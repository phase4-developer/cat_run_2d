# MV-SPEC-02 용어 ↔ 표 id 대조표

작업 `MV-SPEC-02` 기준선(원문 modifiedTime `2026-11-10T10:37:50.996Z`). 새 기획서(Google 문서 「냥법사 : 종이 마을 구출기」, 사본 [Source/](Source/README.md))의 용어마다 지금 저장소 표(`Assets/Game/GameData/Table/TSV/*.txt`, 설계 [07_Tables.md](../MV-SPEC-01/07_Tables.md))의 정수 id를 붙였다.

- 표기: 본문·보고서에서 `마법서 탑(105001001)`처럼 쓴다. 표 이름은 `NNN_이름`, id는 TSV 첫 열이다.
- 「MV-SPEC-01 이름」은 지금 표·기획서의 달동네 이름(07·08의 이름 열)이다.
- 매칭 상태: **일치**(뜻·역할이 같고 이름도 같음) / **이름만 다름**(역할 같고 이름만 다름) / **값 다름**(같은 행이지만 수치·범위가 다름, 차이 보고서 참조) / **표에 없음** / **후보**(확신 없음 — 추정으로 채우지 않았다, 질문 목록 T-Qn) / **여러 개 후보**.
- 사용자 요청 원문(2026-11-10, 중계 경유): 「여기서 용어들이 현재 테이블과 매칭이 한국어로만 되어있어서 힘드니까 이부분을 혼선이 안오게 아이디를 뒤에 타워(10010001) 이런씩으로 대조해서 맞춰주면 좋을거같아」. 예시의 `10010001`은 실제 표에 없는 id다. 탑의 실제 id는 `105001001`이다.
