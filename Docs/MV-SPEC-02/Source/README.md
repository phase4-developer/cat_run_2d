## 사본 만드는 규칙 (다음 갱신도 같게)

비교가 원문 변경만 잡도록 정규화 방식을 고정한다.

1. 파일 경로는 바꾸지 않는다. 같은 파일을 덮어쓰고, 지난 사본과의 차이는 `git diff`·`git log -p -- Docs/MV-SPEC-02/Source/`로 본다.
2. 먼저 `get_file_metadata`로 `modifiedTime`·`etag`를 읽는다. 위 값과 같으면 사본을 다시 만들지 않는다.
3. `read_file_content` 결과의 서식 이스케이프(`\*\*`, `\\[`, `\~`, `&#10;`)를 풀고, 표는 GFM 표(첫 줄 머리)로, 회색 박스(한 칸 표)는 `>` 인용으로, 목차는 장마다 한 줄로 적는다. 굵게·표시([원작] 등)는 원문대로 둔다. 문장·숫자·순서는 바꾸지 않는다.
4. 탭 하나 = 파일 하나, 이름 `NN_짧은이름.md`. 새 탭이 생기면 파일을 더하고 위 표에 행을 더한다. 탭이 비어 있으면 「비어 있음(작성 예정)」 줄을 둔다.
5. 위 표의 `modifiedTime`·`etag`·읽은 날을 고치고, 차이 보고서에 새 판 절을 더한다.
6. 문서 규칙상 상세 수치는 별도 시트에 있다(04 탭이 링크를 둘 예정). 시트가 생기면 시트 사본 규칙을 이 절에 더한다.
