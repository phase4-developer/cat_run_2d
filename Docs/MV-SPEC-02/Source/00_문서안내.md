## 탭 작성 규칙

- 탭 이름은 'NN. 항목명' 형식으로, 번호 순서대로 추가한다.
- 각 탭 첫머리에 목적 · 기준(원작 / 프로토 / 컨셉) · 최종 수정일을 적는다.
- 표기 규칙 [원작] [프로토] [미확인] [컨셉]은 01 탭 기준을 모든 탭에 공통 적용한다.
- 상세 수치 테이블은 별도 시트로 관리하고, 기획서 탭에는 요약과 링크만 둔다.
