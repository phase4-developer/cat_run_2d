계단 생성 구간(마법진 포털)에 도착하면, 그 판에서 모은 마나 수만큼 계단을 쌓고 고양이가 오르는 연출.
연출 중 카메라가 "뒤 시점 → 옆(횡스크롤) 시점"으로 실제 회전했다가, 끝나면 다시 뒤 시점으로 돌아온다.
상태 흐름: Run → Climb(진입 회전 → 오르기 → 도착) → Run + 카드 룰렛

## 1. 시작 조건

- 달리다가 계단 생성 구간(마법진 포털)에 닿으면 정산이 시작
- 그때까지 모은 계단 수 = 오를 칸 수예요. 모은 계단이 없다면 무시하고 지나감
- 시작하는 순간 날아가던 투사체를 모두 지우고, 마나를 0으로 돌려요.

## 2. 계단 만들기

- 칸 수: 계단 1 = 1칸이고
- 칸 크기: 높이 0.42m, 깊이 0.72m예요.
- 계단 길이: 계단 전체 길이(칸 수 × 0.72m)만큼 앞쪽 트랙을 통째로 뒤로 밀어서 공간을 만들어요.
- 지금 지형은 아래층으로 남고, 계단 꼭대기 높이에 다음 지형을 새로 깔아요.
  - 월드 이동: 포탈 뒤쪽 트랙 전체(오브젝트·게이트·다음 구간)를 (k*STEP_D + 8)만큼 뒤로 밀어 공간을 만든다.
  - 지금 지형은 아래층으로 남김
  - 계단 꼭대기 높이(base + dH)에 다음 지형을 새로 깔아 런이 끊기지 않게 함
  - 칸 i: z 구간 [z0 + i*D, z0 + (i+1)*D], 윗면 높이 = base + (i+1)*H
  - (칸은 바닥에서 윗면까지 꽉 찬 기둥 블록. 앞판/옆판/윗판 3면)
- 그래서 런이 끊기지 않고 같은 트랙에서 위로 이어져요.
- 칸 색: 등급이 바뀌는 구간부터 각 등급마다 계단 색이 변경
  - 5 이하: Obj_ClimbStep
  - 5 이상: Obj_ClimbStep_C
  - 10 이상: Obj_ClimbStep_UC
  - 20 이상: Obj_ClimbStep_R
  - 40 이상: Obj_ClimbStep_E
  - 75 이상: Obj_ClimbStep_L

## 3. 카메라 회전 (뒤 → 옆)

- 0.42초 동안 카메라가 실제로 고양이 둘레를 돌아서 **옆모습(횡스크롤 시점)**으로 바뀌어요.
  - 회전 시간 0.42초, 보간 k → smoothstep(k) = k*k*(3-2k)
- 목표 위치: 고양이 옆 9.2m, 위 2.1m에서 고양이 머리 쪽(+1.5m)을 봐요.
  - 정산 중 목표 (cat = 고양이 위치):
  - lookAt = cat + (0, 1.5, 0.35)
  - camPos = cat + (9.2, 2.1, 0.35) // 고양이 오른쪽 옆
- 보간: 각도, 거리, 높이를 원기둥 좌표로 이어서 부드럽게 돌아요.
  - 보간 방식: 원래 카메라와 목표 카메라를 각각 (각도, 수평거리, 높이)로 바꿔 각각 선형 보간 (원기둥 좌표)
  - → 직선 이동이 아니라 고양이 둘레를 도는 궤적
- 가림 처리: 도는 동안 카메라와 가까운 쪽 길가 가게와 소품은 투명해져요. 땅도 가까운 쪽을 잘라 단면을 보여 줘요(디오라마 느낌).
  - 회전 비율 e에 맞춰 처리할 것:
  - 카메라 쪽(가까운 쪽) 길가 가게·소품 알파 → 0
  - 바닥은 가까운 쪽을 잘라 단면 표시 (디오라마 느낌)
- 끝나면 같은 0.42초로 역방향 회전

## 4. 오르기

- 시작 시점: 0.05초 뒤 바로 오르기 시작해요. 달리던 속도를 그대로 이어서 멈칫하지 않아요.
- 걸리는 시간: 0.8초 + 칸 수 × 0.09초예요. 10칸이면 1.7초, 50칸이면 5.3초이고, 칸 수에 비례해서 길어져요.
- 속도: 일정한 속도로 올라가요(감속 없음).
- 칸 등장: 고양이보다 5칸 앞까지 미리 나타나요. 위 5m에서 0.2초 동안 떨어져 쌓이고, 칸마다 '틱' 소리가 나요.
  - 칸 등장:
  - 인덱스 < ceil(pos + 5)인 칸이 고양이 5칸 앞까지 미리 등장
  - 등장 연출: 위 5m에서 0.2초 동안 떨어짐, y = 5 * (1 - f)^2, f = st.t / 0.2
  - 칸 등장마다 'tick' 효과음
- 고양이 위치: 계단 앞 모서리를 잇는 비탈 선 위를 미끄러지듯 따라 올라가요.
- 고양이 그림: 지금 무기 등급의 cat_stair 이미지 한 장을 써요. 앞에 붙은 cat_stair_wheel 바퀴가 오른 거리만큼 시계방향으로 굴러요(한 칸에 약 0.6바퀴).
  - 바퀴 cat_stair_wheel:
  - 고양이 그림 앞에 그림 (원본 512px 기준 바퀴 중심 (251, 417.5), 고양이 발 기준점 (240, 487))
  - 회전각(시계방향) = pos * hypot(H, D) / r * 0.6875, r = 0.373m
  - → 한 칸에 약 1.54rad(약 88°, 0.24바퀴)
  - 계단이 멈추면 바퀴도 멈춤
- 고양이 움직임: 경사를 따라 기울면서, 좌우로 살짝 흔들리고 통통 튀어요.
  - 기울기 = (-slope*0.6 + sin(w*8*0.5)*0.06) * k (k = 회전 진행 보간)
  - 통통 = |sin(w*8)| * 0.04m
  - 오르기 전후 정지 중: 기울기 -slope*0.18 + sin(시간*3)*0.045

## 5. 오르는 동안 보상 연출

- 등급이 오를 때:
  - 그 등급 효과음이 나고, 그 색의 폭발과 불꽃이 터져요.
  - 화면이 살짝 흔들리고, 등급색으로 0.09초 번쩍여요.
  - 화면 가운데에 등급 이름("RARE" 등)이 커졌다 사라지고, 고양이 주변에 종이 별 조각이 튀어요.
- 진행 표시: 카메라가 옆으로 거의 다 돌면(60% 이상) 위쪽에 진행 칸 수가 떠요. HUD 숫자도 남은 칸이 줄고 오른 칸이 늘어나요.

## 6. 끝

- 도착: 끝까지 오르면 모든 칸이 제자리에 고정되고 착지 소리가 나요.
- 마무리 연출: 0.12초 뒤 꼭대기에 "N칸 올라옴!" 글자가 마지막 등급색으로 뜨고, 금색 폭발이 터져요.
- 런 재개: 고양이가 계단 끝에 서고, 지면 높이가 계단 높이만큼 올라간 채로 런이 다시 시작돼요. 카메라는 0.42초 동안 다시 뒤쪽 시점으로 돌아와요.
