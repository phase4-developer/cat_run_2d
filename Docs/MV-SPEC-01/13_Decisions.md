### D-02 Framework 연결 방식 — 사용자 결정 대기

| 선택지 | 바뀌는 것 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A. 외부: 고정 tgz (권장)** | `Packages/manifest.json`이 `Packages/JJEvol/*.tgz`를 가리킴. 시험 중 패키지(씬·로그인·통신·광고·통계·결제·알림·effects.ui·audio.addressables·tables.authoring·localization.authoring)는 고정본 전까지 게임 인터페이스 + 스텁 | 게임이 Framework 변경에 흔들리지 않는다. HellEscape와 같은 방식 | 시험 중 패키지가 고정될 때까지 해당 기능은 스텁으로 개발하고 나중에 교체 작업이 생긴다 |
| B. 내부: `file:` 폴더 연결 | manifest가 `file:C:/Project/JJEvolFramework/...` | 모든 패키지를 바로 쓴다. 스텁·교체 작업 없음 | Framework 수정이 곧바로 게임에 퍼진다. 재현성·검증 기준이 흔들린다. 회사 저장소가 개인 폴더 경로에 기대게 된다 |

### 13.3.5 표 구조 방침 — 확정

2026-11-09 사용자 「테이블 구조는 정크버스터즈 참고 많이해줘 지금 이 게임도 제대로 테이블 구조가 잡히지 않은거 같아 보상같은건 consumeData형태로 테이블에서 수정 가능해야하고 리소스도 테이블에서 설정가능해야해」. 반영 내용은 [07](07_Tables.md) 앞부분(정크버스터즈 대비 구조 결정)에 있다: 번호 대역 `NNN_camelCase`, 정수 id, consumeData 3열 + `07_consumeType`, 리소스 열 직접 설정, `16_levelPrice` 행 비용, 행 id 문구 키.

같은 말의 「지금 이 게임도」가 HellEscape 저장소의 현재 표를 뜻한다면, 그 표 재구성은 이 기획서(문서 작업) 범위 밖의 별도 작업이다.
